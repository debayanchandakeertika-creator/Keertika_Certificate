Please follow the instructions below:

  • Download the excel file
  • There are 6 sheets in the output excel file
  • Sheet 1 (Exact Match with Bill): Contains all the statements with an exact match with a bill
  • Sheet 2 (Not Exact Match): Contains all the statements where there is no exact match but the nearest match
  • Sheet 3 (Not Bill Data): Contains all the statements where no bill data was found against a probable client code
  • Sheet 4 (Client Code Not Found): Contains all the statements where no client code was found against a probable client name
  • Sheet 5 (Non-Credit Transaction): All debit transactions
  • Sheet 6 (Undetected Transaction): Undetected Transactions
